# Upload — 10 November 2026: perbaikan 404 di Search Console

Folder ini adalah SELURUH situs, disinkronkan dengan repo terbaru
(commit 142d871 "Curhat") plus perubahan di bawah. Timpa semua isi
repo / public_html dengan isi folder ini.

## Yang berubah

**Sumber 404: link template yang terbaca Google**
- 56 dari 62 URL di laporan "Not found (404)" berbentuk
  /produk/x/{{ p.href }}. Itu bukan halaman: Google membaca template mentah
  di dalam <x-dc> sebelum JavaScript mengisinya.
- Di 101 halaman, 633 atribut href="{{ ... }}" / src="{{ ... }}" di dalam
  template diganti dc-href / dc-src. support.js mengembalikannya jadi
  href/src saat render, jadi tampilan dan link di browser tidak berubah.
  Bonus: browser tidak lagi meminta gambar /{{ p.image }} di beranda.
- support.js dimuat dengan ?v=20261110 supaya browser lama tidak memakai
  support.js versi cache (tanpa ini, link akan mati sampai 7 hari).
- Sumber _src/landing dan _src/curhat ikut diubah; build ulang menghasilkan
  file yang sama persis.

**.htaccess**
- URL lama yang mengandung {{ atau }} sekarang dijawab 410 Gone, bukan 404.
  Google menghapus 410 lebih cepat.
- 6 produk tanpa halaman (belum ada foto) dialihkan 301 ke bagian katalog:
  krusifiks-jati, gelang-manik-tenun, batik-agnus, set-henna-salib,
  lilin-hortus, rosario-via-lucis.
- /jurnal/artikel/ugc-... dialihkan 301 ke kartunya di /jurnal/.
- www.peziarah.com sudah dialihkan ke peziarah.com sejak sebelumnya; dua URL
  www di laporan adalah crawl lama.

## Setelah upload, cek
1. Buka satu halaman produk dan beranda, klik beberapa link (produk lain,
   kategori, WhatsApp). Semua harus jalan seperti biasa.
2. Buka https://peziarah.com/produk/tas-romo/%7B%7B%20p.href%20%7D%7D
   → harus muncul halaman 404 Peziarah dengan status 410
   (cek di Search Console → URL Inspection → Test live URL).
3. Buka https://peziarah.com/produk/krusifiks-jati/ → pindah ke /katalog/#salib.
4. Search Console → Pages → Not found (404) → VALIDATE FIX.
   Validasi butuh beberapa minggu. Jumlah akan turun bertahap; URL 410
   pindah ke kategori lain lalu hilang.

# Upload — 9 November 2026 (malam): Curhat Katolik

Folder ini adalah SELURUH situs, disinkronkan dengan repo terbaru
(commit 6632cf4 "Change Landing") plus perubahan di bawah. Timpa semua isi
repo / public_html dengan isi folder ini.

## Yang berubah

**Halaman baru: /curhat/ — Curhat Katolik**
- Curhat lewat WhatsApp Peziarah (nomor yang sama dengan toko untuk
  sekarang) dengan admin Peziarah. Chat 30 menit Rp 15K, chat 60 menit
  Rp 25K, telepon 30 menit Rp 25K, telepon 60 menit Rp 45K. QRIS/transfer
  sebelum sesi. Senin–Sabtu 10.00–21.00 WIB.
- Cara kerja 4 langkah, janji (hanya admin yang membaca, tidak disimpan,
  tanpa ceramah, tidak ada kontak di luar layanan, boleh berhenti), batas
  kerahasiaan (nyawa terancam), usia 18+.
- Pendampingan (tingkat 2): romo (persembahan, saran Rp 150K, diteruskan
  utuh), psikolog berizin Rp 300K, konselor pernikahan & keluarga Rp 250K,
  pendamping awam Rp 150K. Biaya curhat dipotong dari sesi pendampingan
  pertama. Pengakuan dosa bukan bagian dari layanan.
- Kotak "Bukan untuk keadaan darurat": 112 / IGD.
- Tombol WhatsApp membuka chat dengan pesan "Halo Peziarah, saya mau
  curhat." — admin bisa langsung mengenali pesan curhat.
- Meta, OG, Twitter, keyword, JSON-LD (Service + harga, FAQPage), blok statis
  untuk Google. Gambar share: assets/og/curhat.jpg.
- Sumber: _src/curhat/ (head.html, body.dc.html, build.py).
  Bangun ulang: python3 _src/curhat/build.py. Header/footer disalin dari
  produk/index.html (komponen Header/Footer design system).

**Tanya Awam (/tanya/)**
- Bagian baru "Mau ngobrol langsung? Curhat Katolik." sebelum kotak darurat,
  plus satu paragraf di blok statis. Tanya Awam tetap gratis dan anonim.

**Footer (95 halaman)**
- Kolom BACAAN: tautan "Curhat Katolik" setelah "Tanya Awam". Komponen
  Footer di design system Peziarah juga diperbarui.

**Lainnya**
- sitemap.xml: /curhat/ ditambahkan; lastmod /tanya/.
- llms.txt: bagian Curhat Katolik (harga, jam, batas layanan).
- README.txt: /curhat/ di daftar halaman.

## Setelah upload

1. Buka https://peziarah.com/curhat/ di desktop dan HP. Klik "Mulai curhat
   di WhatsApp": chat terbuka dengan pesan "saya mau curhat".
2. Buka /tanya/: bagian Curhat Katolik muncul sebelum kotak darurat.
3. Cek footer halaman mana pun: BACAAN → Curhat Katolik.
4. Search Console → URL Inspection → https://peziarah.com/curhat/ →
   Request indexing.
5. Sebelum promosi: siapkan admin (pelatihan mendengar, skrip darurat,
   debrief bulanan), cara bayar QRIS, dan daftar pendamping per peran.
   Halaman menjanjikan pendamping tersedia — pastikan minimal satu per peran.
